♟ Game Tab

♙ New Game
Resets the board and starts a fresh game with the current player configuration.
📂 Load Save
Restores your most recently saved game from local storage.
💾 Save Game
Saves the current position and move history to local storage (keeps the 3 most recent saves).
⚙️ Player Setup
Switches to the Setup tab to change who controls each side.
🏛️ Classic Games
Switches to the Learn tab to step through a famous historic game.
🎯 Practice Openings
Switches to the Learn tab to load a well-known opening position.
Status log
Live feed of game events, moves played, and server responses.

⚙ Setup Tab

Player Type
Choose Human (enter a name) or AI for each side.
AI Engine
Stockfish (local), OpenAI GPT, DeepSeek, or Claude.
Skill Level
1 = easiest, 20 = strongest. Applies to Stockfish only.
Start New Game
Begins a game using the current player settings.

📚 Learn Tab

Classic Games
Select a famous game from the dropdown to load it for step-through review.
⏮ ◄ ► ⏭
Step backward/forward one move at a time, or jump to the start or end of the game. Commentary appears below the controls when available.
Practice Openings
Tap an opening name to load its starting position on the board so you can continue playing from there.

📋 History Tab

Move table
Numbered list of every move played in the current game, showing the notation for White and Black each turn.

🧠 Expert Tab

Quick buttons
Pre-written prompts — Analyse position, Best move, Opening, Strategy — sent to the AI expert with one tap.
Input + Ask
Type any chess question; the AI answers in the context of the current board position.
